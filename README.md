# HR-Analysis-Attrition-
In this project, I saw a relative increase in the percentage of employees leaving the company, and by applying some analyses and analytical tables to the data available from the HR department, I was able to provide some of the main reasons that had a direct and influential impact on the largest percentage and some secondary reasons that influenced parts of the total percentage, 
The tools I utilised for this project included Excel (specifically Power Query, Power Pivot, pivot charts, and pivot tables) 
Data visualisation techniques using Excel and pivot charts.
